# まるや製パン ホームページ　使い方

架空のパン屋「まるや製パン」のホームページです。自分のPCのブラウザで見るためのものです。

## ひらき方

`index.html` をダブルクリックすると、ブラウザ（Chrome / Edge など）で開きます。

- ネットにつながっていると、看板や見出しがレトロな書体（Google Fonts）になります
- つながっていなくても、ふつうの書体で問題なく表示されます

## ファイルの役割

| ファイル | 役割 | ふだんさわる？ |
|---|---|---|
| `index.html` | ページの中身と骨組み | メニューや営業時間を変えるとき |
| `style.css` | 見た目（色・配置）。先頭の「色の設定」で色を変えられます | 色を変えたいとき |
| `news.js` | **おしらせの中身** | **おしらせを書くとき** |
| `main.js` | おしらせを並べるプログラム | さわらなくてOK |
| `images/` | 写真を入れるフォルダ | 写真を入れるとき |

## おしらせを追加する

1. `news.js` を右クリック →「プログラムから開く」→「メモ帳」
2. `const MARUYA_NEWS = [` の下に、次の形で1行足す

   ```
   { date: "2026-11-01", title: "見出し", body: "本文" },
   ```

3. 上書き保存（Ctrl + S）して、ブラウザを再読みこみ（F5）

自動でやってくれること：

- 日付の新しい順に並びます（書く場所はどこでもOK）
- 7日以内のおしらせに「NEW」がつきます
- 未来の日付で書いたおしらせは、その日まで表示されません（予約投稿）
- 最初は3件だけ表示し、残りは「もっと見る」で開きます

うまく表示されないとき：ページに「おしらせを読みこめませんでした」と出たら、
`news.js` の **カンマ「,」のつけ忘れ** や **「"」の閉じ忘れ** を確認してください。

## 写真を差し替える

いまは7枚とも写真（`.jpg`）です。一番上はもらった写真、パンの6枚は Pexels の無料写真です。
Claude が描いたイラスト（`.svg`）も残してあるので、`index.html` の `.jpg` を `.svg` に戻せばイラストに戻ります。
本物の写真に変えたいときは、写真を `images/` フォルダに下の名前で保存し、
`index.html` の中の `images/〇〇.svg` を `images/〇〇.jpg` に書きかえてください。

| 場所 | 今のイラスト | 写真にするときの名前 |
|---|---|---|
| 一番上の大きな写真（横長がおすすめ） | `hero.svg` | `hero.jpg` |
| あんぱん | `anpan.svg` | `anpan.jpg` |
| メロンパン | `melonpan.svg` | `melonpan.jpg` |
| カレーパン | `currypan.svg` | `currypan.jpg` |
| 食パン | `shokupan.svg` | `shokupan.jpg` |
| クリームパン | `creampan.svg` | `creampan.jpg` |
| コッペパン | `koppepan.svg` | `koppepan.jpg` |

無料で使える写真サイト：Unsplash（unsplash.com）、Pexels（pexels.com）、ぱくたそ（pakutaso.com）。
「bread」「パン」「bakery」などで検索してダウンロードしてください。
使う前に各サイトの利用規約（利用条件）を確認しましょう。

注意：拡張子が `.jpg` でない写真（`.jpeg` や `.png`）は、ファイル名を変えるか、
`index.html` の該当する `images/〇〇.jpg` を書きかえてください。

## パンを押したときの「おすすめ」を変える

パンの写真を押すと、大きな写真と「このパンに合う飲み物」「いっしょにどうぞ」が出ます。
おすすめの中身は `menu.js` の先頭にある `MARUYA_PAIRING` に書いてあります。
飲み物の名前（`name`）や理由（`why`）、いっしょにすすめるパン（`id`）を書きかえてください。
パンの写真・名前・値段・説明は `index.html` から自動で読みこむので、そちらを直せば窓の中も変わります。

## 地図を押したときに開く場所を変える

地図を押すと Google マップが開きます（いまは架空の住所なので、場所は見つかりません）。
開く場所を変えたいときは、`index.html` の `class="map"` の行の下にある
`query=こむぎ市 ほんまち三丁目 2-1` の「`query=`」のうしろを、本当の住所やお店の名前に書きかえてください。
